H2: 강한 가설. PSR이 조절변수일때, efficacy message -> efficacy belief가 더 강하게 나타난다

mediation 모델

efficacy -> beliefs (mediator) -> action intention
여기서, beliefs를 거쳐야만한다고 주장하면 full-mediation 모델 (매우 강한 주장)

그런데, efficacy -> action intention도 포함됨

이 논문은 conditional process model

efficacy -> (PSR; 조절) -> beliefs (mediator) -> action intention
여기서, efficacy -> action intention도 포함 (즉, full-mediation까지 주장하지는 않음)

moderated mediation model (조절된 매개모형)

물론 여기서 moderator인 PSR이 beliefs -> action intention 이런 경로에는 왜 없어? 같은 질문도 나오곤 함
