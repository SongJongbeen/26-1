# 홍위고등학교

## 설정

- 2026년 대한민국
- 고등학교 (공학)
- 일반고등학교 (평범한 고등학교)
- 홍위고등학교
- 서울에 위치
- 건물 3채 (식당, 본관, 별관)
  - 본관 - 1층: 교무실, 보건실 / 2층~4층: 각 학년별 교실
  - 별관 - 1층: 강당 / 2층: 과학실, 음악실, 미술실 / 3층: 자습실, 컴퓨터실, 방송부실
  - 후생관 - 식당, 매점, 기숙사, 도서실
- 문과, 이과, 실업반, 예체능반으로 분리되어있음

## 규칙

- (최소) 미션으로 제공되는 1주 1회 연성 + 자율 1회 연성 (관계가 있어야함)
- 앤캐 없이
- 캐에 몰입하기
- 기간은 4월 1일 ~ 29일 (30일은 총결산 - 각종 시상식 진행)
- 최다연성 / 최고인기 etc...
- 적당히 예의 지키면서 하기! 문제 생기면 영안의 매우 매우 독재적인 판단에 따름

- 이름

- 자라온 배경
- 특이사항

- 1주차 (4/1~4/7) / 3월
  - 입학식 (개학 및 반배정)
  - 반장선거
  - 동아리 가입
- 2주차 (4/8~4/14) / 4월
  - 중간고사
  - 교내 요리대회
- 3주차 (4/15~4/21) / 5~6월
  - 교생실습
  - 스승의날
  - 체육대회
- 4주차 (4/22~4/28) / 7월
  - 동아리 발표회
  - 방학식
